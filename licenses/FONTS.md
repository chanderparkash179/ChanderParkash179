# Embedded fonts

The animated README SVGs embed the following fonts as base64 WOFF2:

| Family (in SVG) | Source font | License file |
| --- | --- | --- |
| SyneEmbed | [Syne](https://fonts.google.com/specimen/Syne) Bold / SemiBold | `licenses/Syne-OFL.txt` |
| JBMonoEmbed | [JetBrains Mono](https://www.jetbrains.com/lp/mono/) Regular / Medium | `licenses/JetBrainsMono-OFL.txt` |

Both families are licensed under the SIL Open Font License 1.1.
